# fatture-fornitori

## Contenuto del repository

- [`etf-quotazioni-downloader/`](etf-quotazioni-downloader/) — software che scarica
  ogni giorno le quotazioni degli ETF da Yahoo Finance e genera un report HTML
  interattivo che evidenzia gli ETF con l'andamento più costante e prevedibile,
  con grafici a 1 e 7 giorni e indicatore MACD. Le istruzioni di installazione
  sono nel [README della cartella](etf-quotazioni-downloader/README.md).
