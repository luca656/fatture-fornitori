# Le mie ricette

Piccola app web (un solo file, `index.html`) per tenere traccia delle ricette che fai.

- Ricette divise per portata: Antipasti, Primi, Secondi, Contorni, Dolci, Pane e pizza, Altro
- Per ogni ricetta: ingredienti, procedimento, note, data e foto del risultato
- Ricerca per nome o ingrediente
- Dati salvati nel browser (IndexedDB); **Esporta / Importa** per fare backup in JSON

Uso: apri `index.html` nel browser (anche da telefono).
